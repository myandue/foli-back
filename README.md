# Foli

## 목적

- 학습을 목적으로 한 python 서비스 구현
- 혼자서 하나의 프로젝트를 완성해낼 수 있을 정도의 프론트엔드 학습

## 목표

- 프로젝트 완성
- 기본적인 Authentication에 대한 이해 및 적용
- 기획/프론트엔드/백엔드/AI 영역을 나누어 스케쥴에 맞춰 진행
- 사용할 프레임워크 및 라이브러리(Django, FastAPI, React)에 대한 학습
- AI 서비스 활용 (Clova Studio, Clova Speech)

# BackEnd

## Tools

- Python
    - Django
- MySQL

## 기능
> ( ): 구현 예정

#### 유저

- 회원가입
- (프로필 조회)
- (프로필 수정)
- (회원 탈퇴)

#### Auth

- 로그인
- (로그아웃)
- access_token 인증
- refresh_token 인증 및 재발급 (refresh_token 블랙리스트)

#### 퀴즈

- 히스토리(검색어/난이도/퀴즈개수) 저장
- (퀴즈 내용 저장)
- AI - 키워드로 퀴즈 생성 서비스 호출 및 클라이언트에게 반환

#### 음성 파일 요약

- 음성 파일 업로드 및 정보 저장
- AI - STT 서비스 호출 및 저장, 반환
- AI - 문서 요약 서비스 호출 및 저장, 반환
- AI - 문서 기반 퀴즈 생성 서비스 호출 및 클라이언트에게 반환
- (AI - 문서 기반 질의응답 Chat Bot 호출)
